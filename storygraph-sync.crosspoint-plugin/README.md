# StoryGraph Sync

Sync reading progress, per-session reading journals, and reading dates from **CrossPoint** / **CrossInk** to **The StoryGraph** from the File Manager Web UI (`/files`).

> **Compatibility:** Tested on **CrossInk 2.0.0 RC3** (XTEInk X4 Pro) and compatible with **CrossPoint 2.0.0 RC / nightly** (`firmware_family: crosspoint`, `plugin_api >= 1`). Per-session duration tracking uses `reader.session` events; firmware builds that only emit `reader.exit` still track reading progress checkpoints seamlessly.

## 1. Install & First Boot

- **Via Plugin Hub (Recommended):** Open **Home → Plugins → Plugin Hub** (or the Plugin Hub WebUI), install **StoryGraph Sync**, then **reboot once** so firmware registers `reader.exit` and `reader.session` subscriptions.
- **Manual SD Install:** Copy the `storygraph-sync.crosspoint-plugin` folder to `/.crosspoint/plugins/storygraph-sync/` via **USB Drive** mode or an SD card reader, enable **Settings → System → Plugins** (or **Connectivity → Plugins**), and **reboot once**.
- Open a book, read, and exit back to Home so firmware records progress in `events.jsonl`.

## 2. Sign In (Browser Cookies)

- **Desktop:** Log into `https://app.thestorygraph.com/` → **F12** → **Network** → reload (**F5**) → click `app.thestorygraph.com` → copy the `cookie` header (or **Copy as cURL**).
- **Phone (no PC):** Open `https://app.thestorygraph.com/` in **Firefox** (Android) or **Safari** (iOS) with the **Cookie-Editor** extension → tap **Export → JSON** (or **Header String**). *(Open `/files` in that same browser so `User-Agent` matches, or use **Export Settings** on desktop and **Import Settings** on phone under **Account Settings → Advanced & Backup**.)*
- Start File Transfer on your e-reader, open `http://crosspoint.local/files`, expand **Account Settings**, paste into **StoryGraph Cookies** (supports cookie headers, Cookie-Editor JSON, Netscape `cookies.txt`, and cURL), and click **Verify Session**.

> Credentials are never written to the microSD card; session cookies stay strictly in browser `localStorage` (use `http://crosspoint.local/files` so they survive DHCP IP changes), and `_storygraph_session` rotates automatically whenever StoryGraph sends `Set-Cookie`. Firmware enforces a 4 KB total request-header limit (`4,096` B, max 16 headers), so the plugin automatically trims non-essential cookies if needed — if you paste a very large header, keeping only `_storygraph_session` and `cf_clearance` avoids header-size errors.

## 3. Link & Sync Books

- **Tracked Books (`events.jsonl` & `reading-history.json`):** Every reading session (`reader.session`) recorded while plugin subscriptions are active is preserved 1:1 as an individual `reading_session` record in `reading-history.json` (never merged or collapsed across same-day sittings, and preserved across `/Books/` → `/Read/` folder moves or `events.jsonl` compaction). Progress advances from `reader.exit` without a companion `reader.session` are recorded separately as `progress_checkpoint` records, and pre-v2 daily aggregates are preserved honestly as `legacy_daily_summary` records. Each session tracks a persistent synchronization ledger (`sessionId → journalEntryId → syncStatus`) with single-candidate interrupted-sync reconciliation (`needs_reconciliation` when multiple ambiguous remote candidates exist). Books moved into `/Read/` after finishing (even when firmware logs a `0%` cache-reset event after moving) are automatically recognized as **100% — Ready**. Books appear inside collapsible **Currently Reading**, **Unlinked & From SD**, and **Read** sections, with clickable StoryGraph title links (`↗`), percentage progress, duration, pages turned, a collapsible per-book **Reading history** diary showing each individual sitting (`Reading session N`, time-of-day range and period like `09:15 · Morning`, individual duration, and `start% → end%`), derived daily/total reading time, and non-wrapping human-readable dates (same-year ranges shortened to `read October 19 → October 21, 2026`). Use the filter tabs (**All**, **Reading**, **Needs Sync**, **Read**, **Unlinked**), quick search box, and **Sort** selector to narrow or reorder the list anytime, click **Link Book** on unlinked rows to match via StoryGraph **Current Reads**, `/browse` search, or Book URL / ID, or click **Ignore** to hide unwanted files without touching your SD card (restorable under **Tools & Preferences → Ignored Books** or **Browse SD Library**).
- **Older or Already-Finished Books:** Expand **Browse SD Library** to browse folders on your SD card on demand and click **Add & Link** on any book. Once linked, click **Mark Read** for finished books — or leave it pre-linked so progress fills in after your next reading session. *(To pull current `%` for an untouched mid-read book immediately, open and exit it once on your e-reader.)*
- **Sync:** Click **Sync Now** on one book or **Sync All** in the header to sequentially update every linked book with new progress (shown in the progress modal with a safe **Cancel** button to stop cleanly after the current book, auto-compacting `events.jsonl` when enabled), or **Mark Read** when finished. Every unsynced reading session is posted chronologically as its own independent sitting to StoryGraph's **Reading Journal** via `/update-progress-with-note` (including time-of-day and sitting duration notes like `20:10–20:55 · 45m read on CrossPoint` by default — customize the **Journal device label** in Account Settings, or uncheck **Include reading duration in StoryGraph journal notes** for blank notes), binding the minted StoryGraph `journalEntryId` in the local synchronization ledger so multiple same-day sittings (even with identical progress or `0%` delta) are preserved without duplicates. Use **Clean Journals** under **Tools & Preferences** anytime to scan linked books on StoryGraph, transfer page credit from un-ledgered stray `100%` artifacts onto `Finished (0 pages read)` entries, and delete bogus `0%` reset artifacts while strictly preserving all ledger-bound and note-bearing reading sessions (including final `100%` sittings). StoryGraph page fetches automatically retry transient `/api/fetch` transport/timeout/502/504 errors up to 2 times with backoff (stopping immediately without reading stale SD cache on HTTP 401/403/503 or Cloudflare blocks), and **Clean Journals** caches a local activity watermark for verified-clean **Read** books so subsequent runs skip already-verified finished books unless new reading sessions or mapping changes arrive. Start and finish dates from your reading history (`startDate` / `lastDate`) are synced to StoryGraph automatically during **Sync Now**, **Sync All**, and **Mark Read** (preserving any earlier start date you already set on StoryGraph for Currently Reading / Rereading books). Use **Sync Dates** in the header anytime to push start/finish dates for previously synced books. You can also import historical sessions via **Import Session History** under **Tools & Preferences** by choosing a `.json`/`.jsonl` file directly or pasting multi-line JSON/JSONL (supports CrossPoint Sync exports, `reading-history.json`, and `events.jsonl` with order-independent deterministic session fingerprints). **Sync All** automatically ignores `0%` open-only exit resets and books already marked **Read** (so finished books are never switched to *Rereading*). If other books in a batch have lower device progress than StoryGraph, you are prompted at most once per batch (or never if **Overwrite lower/0% without asking** is enabled).
- **Tools & Preferences:** Expand **Tools & Preferences** for **Clean Journals**, **Compact Outbox**, **Import Session History** (`.json`/`.jsonl` file or paste), **Ignored Books** (restore hidden books anytime), and batch toggles (or click **Open Journal ↗** / **Clean Journal** directly inside an individual book's **Reading history**). **Account Settings** also includes a **How to get cookies?** guide, a **Show/Hide** cookie toggle, a live **Headers: X.X / 4.0 KB** meter, a live journal note preview, and **Advanced & Backup** (**User-Agent**, **Export Settings**, and file-based **Import Settings**).
- **Journal unsynced:** A linked book whose progress already matches StoryGraph but still has reading sessions that are not in the Reading Journal shows a **Journal unsynced** badge. It also appears under **Needs Sync** and is included in **Sync All**.
- **Needs reconciliation:** If a journal post was interrupted and StoryGraph now has more than one matching entry, that session is flagged instead of being posted again. Click **Open Journal ↗** to check StoryGraph, then choose **Mark Synced** (the entry is already there, so nothing is posted) or **Retry** (the entry is missing, so the session is queued again for the next **Sync Now** / **Sync Journal**).

## 4. Historical Progress Backfill (Optional USB Tool)

To recover reading percentages, durations, page turns, and dates from before the plugin was installed (or after moving books to `/Read/`), use the optional `backfill_sd.py` script from the GitHub repository in **USB Drive** mode:

```bash
python backfill_sd.py --write-sd
```

*(Pass `--sd-root E:\` if auto-detection doesn't find the drive.)* Eject safely, switch back to **File Transfer**, and reload `/files` — historical percentages, reading times, and dates appear automatically via `backfill.json` without modifying `storygraph-map.json`.
